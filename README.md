# 灶边笔记

一个无需构建的中文烹饪教程目录，按厨师、菜系、口味、做法等标签查找菜品，保留来源链接与已整理的文字笔记。

## 网站文件

- `index.html`：页面入口。
- `style.css`、`app.js`：样式和交互。
- `data.js`：原有食谱目录及来源依据。
- `tag-enrichment.js`：逐条标签核对补充，区分原片依据、常见做法参考与编辑建议。
- `laofangu.js`：老饭骨官方合集的教学目录、厨师分类及筛选说明。
- `covers/`：对应原视频的展示封面。
- `fonts/`：字体及其许可证。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

不需要安装依赖或执行构建命令。所有本地资源均使用相对路径，支持 GitHub Pages 的项目子路径。

## GitHub Pages

在仓库的 **Settings → Pages** 中，将来源设为 **Deploy from a branch**，选择 **main** 分支和 **/ (root)**，然后保存。等待部署成功后，以 Pages 设置中显示的网址为准。

更新网站时，将修改后的静态文件提交到 `main`，GitHub Pages 会重新部署。

## 菜单交互

- 筛选面板每次打开页面默认收起；收起时已选标签继续生效，并在面板下方显示。
- 「随机展示 12 道菜」从当前厨师、搜索与标签结果抽取，不放入待核候选；同名菜只选一个版本，不足 12 道时全部显示。改变筛选会返回常规目录，点击「再随机」可重新抽取。
- 「今日翻到」按浏览器本地日期每天轮换，同一天刷新保持一致；跨午夜或重新唤醒页面会自动更新。轮换池不含待核候选，同名菜保留一个版本。
- 分类合并只改变菜单入口，不改写原厨师署名、来源账号或合集出处，全部 945 条记录（918 条主目录、27 条待核候选）继续保留。
